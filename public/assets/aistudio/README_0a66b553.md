# PathProof — Phase 1 Documentation Pack

**Phase:** Career Discovery & Intelligence  
**Version:** 1.0  
**Project:** Software Construction & Development semester project

This folder contains the Phase 1 project documentation in Markdown. Phase 1 is a standalone, demonstrable first release. Phase 2 capabilities such as practical career challenges, learning roadmaps, portfolio evidence, counsellor workflows and advanced reassessment are documented as future scope and must not be represented as implemented in Phase 1.

## Important project notes

- Complete student/team and supervisor fields before submission.
- Replace illustrative examples with your actual survey findings and curated job-evidence sample.
- Always show job-evidence sample counts, source URLs, collection dates and verification dates when presenting statistics.
- Career alignment and skill coverage are separate measurements. Do not present either as a probability of employment.
- Use only supported, verified data in recommendations.
- Phase 1 user roles are Student and Administrator unless the project supervisor approves a change.
